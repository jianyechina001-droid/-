# 款研

面料和款式检索工作台，包含品牌检索、Pinterest AI 检索词、浏览器图片导入与本机图片复核。

## 开发

使用 Node.js 24。在本目录运行 `node tool/local.mjs`，打开 http://127.0.0.1:4175/。
运行 `node tool/build.mjs` 生成页面和浏览器助手。在 Edge 扩展管理页加载生成的浏览器助手目录。
运行 `node --test` 执行测试。

AI 功能依赖 Windows 运行包。将现有分享版的 .ai-runtime 目录复制到本仓库根目录即可沿用模型和运行环境。
视觉模型服务使用本机 11436 端口。品牌网站登录由浏览器管理。
